### 6.2 release 构建：此前一直是坏的，现已修复

首次尝试 `:app:assembleRelease` 即失败，根因是手写种子 `app/src/main/baseline-prof.txt` 格式不被 AGP 接受：

1. 原写法 `HSPLcom/huaying/xstz/MainActivity;->*`（通配方法规则）
   → `expandReleaseArtProfileWildcards` 抛 `String index out of range: 37`（该行正好 37 字符）
2. 改为带 flags 的纯类规则 `HSPLcom/.../MainActivity;`
   → 报 `Class rules don't support flags, but 'HSP' were specified`
3. **正确格式**：类规则**不带 flags**，方法规则才带 flags 且需完整签名

```
类规则     Lcom/example/Foo;                                    ← 不带 flags
方法规则   HSPLcom/example/Foo;->onCreate(Landroid/os/Bundle;)V  ← flags + 完整签名
```

修正后 `:app:assembleRelease` 通过（3m46s）。**这说明在此之前 release 从未成功构建过**，
该缺陷一直被 debug 构建掩盖。
