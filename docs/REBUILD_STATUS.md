## 已知偏差与限制

1. **模拟器无实时模糊**：软件渲染下 hazeBlur 输出不透明近似色，由
   `GlassCapability` 降级为半透明渐变。**真机才会走 RenderEffect 真模糊**，
   因此 92~95% 的观感目标目前只验证了布局/配色/字号/对比度，未验证模糊质感。
2. **模拟器不稳定**：qemu 37.2.13 在高负载下 `0xc0000005` 崩溃（当日 4 次，
   2 次在构建期间）。已用 `tools/ensure-emulator.ps1` 自动恢复。
3. **阶段 4、5 未开始**：动效编排、无障碍全量走查、R8 实测、
   baseline profile、签名 release 构建均未做。
