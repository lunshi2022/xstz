## 关键结论（供后续会话复用）

1. 项目属「事实性停更」：远程 main 最后提交 2026-06-10，本地分支 3 个提交从未推送；GitHub 未 archived；单人维护、0 star、唯一 Release 下载 2 次。
2. 已无法商业化分发：targetSdk=34，而 Play 自 2026-08-31 起要求 ≥36；release 构建用 debug 签名。
3. 三个必须先修的 P0 数据缺陷：
   - `EncryptedDoubleConverter` 列级加密导致 `FundDao` 三个 `SUM()` 查询结果错误（目前靠应用层重算规避，是定时炸弹）
   - 导出加密绑定本机 AndroidKeystore，换机**必然**无法解密，"备份"功能实质失效
   - `allowBackup=true` + Keystore 加密 → 云备份恢复后金额全部解不开
4. 架构反模式：MainScreen 用空 Box 占位 NavHost + 外层 AnimatedContent 叠加渲染（为绕开 SizeTransform 裁剪问题），放弃返回栈/状态保存/深链。
5. 死代码：`ui/animation` 2843 行中 5 个文件零引用。
6. 文案零国际化：`stringResource` 使用 0 处，200+ 条 strings.xml 闲置。
7. 版本比较 bug：versionCode=166 vs parseVersionCode("1.6.5")=10605 → 恒判定有更新。

## 技术约定（本项目重开发）

- 玻璃只用于导航层，不用于内容层；玻璃不叠玻璃；同屏 ≤3 个玻璃面
- 圆角必须用 SquircleShape（超椭圆），不用 RoundedCornerShape
- 禁止 `Modifier.blur` 做背景模糊，必须 Haze source/effect 双端
- 备份加密必须口令派生（跨设备可恢复），不得用设备 Keystore
- 金额存 Long（分/厘），不用 Double

**发现并修正一处方案内部矛盾（重要）**：
`SquircleShape.kt` 默认超椭圆指数 n=2.8，而 REBUILD_PLAN 8.3 原文写「指数 n≈4~5」。
